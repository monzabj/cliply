`LICENSE-Gamepad-Asset-Pack.txt`, included with the desktop application.

Source: https://github.com/AL2009man/Gamepad-Asset-Pack

- `dualsense.svg`: DualSense Controller Image / Default / Theme SVG /
  DualSense VSCView SVG.svg
- `xbox.svg`: Xbox Wireless Controller Images / Default Theme / Theme SVG /
  Xbox Series X Color / Xbox Series X Controller VSCView Black.svg

Adaptations: removed editor metadata, local author paths and unused attributes;
made the viewBox scalable. Clipper's renderer highlights the individual shapes,
moves sticks and fills analog trigger shapes. All rendering is local.

The complete keyboard/mouse map is drawn by Clipper in `keyboard-map.js`.
Keyboard reference reviewed: https://kenney.nl/assets/input-prompts (CC0).
No Kenney asset files are incorporated.
